03 — Projects

Featured project.

A hands-on cybersecurity build. More projects on the way — this section grows with each new one.

Featured Project · Cyber Security
🛡️
PhishGuard
Explainable Phishing Website Detection & URL Security Analysis

PhishGuard is an explainable phishing website detection and URL security analysis system that evaluates suspicious URLs using multiple security indicators and produces a transparent 0–100 risk assessment. It's designed to help users understand why a URL may appear suspicious instead of relying on a black-box verdict.

"Built to learn by building."

Python Flask HTML5 CSS3 JavaScript SQLite DNS WHOIS SSL/TLS tldextract cryptography Netlify Render Git pytest
